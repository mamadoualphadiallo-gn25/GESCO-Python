# GESCO-Python

Logiciel professionnel de gestion des notes scolaires, développé en Python avec PySide6 et SQLite. Application Windows autonome, utilisable hors ligne.

## État du projet

Initialisation du socle technique. Les modules seront ajoutés progressivement : gestion scolaire, élèves, notes, calculs, bulletins PDF, classements, import/export Excel, sauvegardes et installateur Windows.

## Développement

Python 3.11+

```bash
python -m venv .venv
.venv\\Scripts\\activate
pip install -r requirements.txt
python main.py
```
